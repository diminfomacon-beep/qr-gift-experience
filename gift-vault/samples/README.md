# Gift Vault samples

Upload the sample images downloaded from Canva into this folder.

- These are the sample QR gift experiences shown on the Gift Vault page
  (the new page being rebuilt in this repository, gift-vault/index.html).
- Upload each sample as a JPG or PNG.
- Name each file after its sample, e.g. "Happy Birthday.jpg" — the Vault
  page displays the images from this folder.
- The QR codes printed on the sample images link to the sample experience
  pages themselves, so the images are the showroom cards.
